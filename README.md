# MaZeKal (מה זה קל) — information page

A static, bilingual (Hebrew / English) information page that links to https://mazekal.co.il.

Files: `index.html` (the page), `logo.png`, `.nojekyll` (tells GitHub Pages to serve the files as they are).

## Publish with GitHub Pages
1. Create a new **public** repository (for example `mazekal`) and upload these files to it.
2. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
3. After a minute or two the page is live at `https://<github-username>.github.io/mazekal/`.

To edit the text, change `index.html`. Each text appears twice: once marked `data-lang="he"` and once marked `data-lang="en"`. Open the page with `?lang=en` to show English first.
